# Beautimax Website

The Beautimax company website, based on the approved Framer design and adapted into a zero-build static website for GitHub Pages.

## Preview with GitHub Pages

This branch can be published directly from the repository root. It does not require Node.js, npm, or a build command.

Entry files:

- `index.html` — page content and structure
- `styles.css` — visual design and responsive layouts
- `script.js` — navigation, reveal effects, and brand carousel

The original Framer React/TypeScript component files are preserved as the design and content reference.
