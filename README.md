# Beautimax

Official website for Beautimax.

Production: https://beautimax.id

## Stack

- React
- TypeScript
- Vite
- GitHub Pages

## Development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

## Deployment

GitHub Pages deploys automatically from `main`.

The `framer-export` branch is retained as the original Framer source and archive.
